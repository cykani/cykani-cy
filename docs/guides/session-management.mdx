## Overview

Sessions maintain browser state across requests — cookies, localStorage, and IndexedDB.

## Session Lifecycle

```
idle → launching → running → stopping → stopped
                                └──→ error
```

## Creating Sessions

```javascript
const session = await strike({
  userDataDir: '/tmp/my-profile',  // Persist state
});
```

## Session Persistence

```javascript
// First session - creates profile
const session1 = await strike({ userDataDir: '/tmp/profile-1' });
await session1.goto('https://example.com');
await session1.close();

// Second session - restores state
const session2 = await strike({ userDataDir: '/tmp/profile-1' });
// Cookies, localStorage, etc. are preserved
```

## Session Methods

| Method | Description |
|--------|-------------|
| `session.id` | Unique session ID |
| `session.page()` | Raw Playwright Page |
| `session.autoPilot()` | AutoPilot instance |
| `session.autonomous()` | Autonomous instance |
| `session.cookies()` | CookieJar |
| `session.record()` | Action recorder |
| `session.har()` | HAR object |
| `session.exportHar(path)` | Export HAR to file |
| `session.close()` | Close session |

## Multiple Sessions

```javascript
// Launch multiple sessions
const sessions = await Promise.all([
  strike({ fingerprint: 1 }),
  strike({ fingerprint: 2 }),
  strike({ fingerprint: 3 }),
]);

// Use each session independently
await sessions[0].goto('https://site-a.com');
await sessions[1].goto('https://site-b.com');
await sessions[2].goto('https://site-c.com');

// Close all
await Promise.all(sessions.map(s => s.close()));
```
