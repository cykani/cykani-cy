## Overview

AutoPilot provides semantic browser automation — no CSS selectors needed. It understands page context and makes decisions like a human.

## Usage

```javascript
const session = await strike({ humor: true });
const ap = session.autoPilot();
```

## Available Actions

### `signIn(credentials)`

Automatically finds and fills login forms.

```javascript
await ap.signIn({
  email: 'user@site.com',
  password: 'secret',
});
```

### `search(query)`

Finds search input and submits query.

```javascript
await ap.search('cykani stealth');
```

### `paginate(direction)`

Clicks next/previous page buttons.

```javascript
await ap.paginate('next');
await ap.paginate('previous');
```

### `findAndFill(label, value)`

Finds input by label and fills it.

```javascript
await ap.findAndFill('email', 'user@site.com');
```

### `findAndClick(label)`

Finds and clicks button/link by text.

```javascript
await ap.findAndClick('Submit');
```

### `fillForm(fields)`

Fills multiple fields at once.

```javascript
await ap.fillForm({
  email: 'user@site.com',
  password: 'secret',
  name: 'John Doe',
});
```
