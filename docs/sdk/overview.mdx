## Core Functions

### `strike(entity?)`

Launch a stealth browser session. Primary entry point.

```javascript
import { strike } from 'cykani-stealth';

const session = await strike({
  humor: true,        // Human-like behavior
  fingerprint: 42,    // Deterministic seed
  platform: 'windows',
  locale: 'en-US',
  timezone: 'America/New_York',
  proxy: 'http://user:pass@host:port',
});
```

### `highTrust(entity?)`

Careful, human-like session with high hesitation.

```javascript
const session = await highTrust();
```

### `aggressive(entity?)`

Fast, low-hesitation session for speed-critical tasks.

```javascript
const session = await aggressive();
```

### `natural(entity?)`

Relaxed human browsing with organic latency.

```javascript
const session = await natural();
```

### `connectOverCDP(endpoint, entity?)`

Connect to a running browser via CDP.

```javascript
const session = await connectOverCDP('http://127.0.0.1:9222');
```

## Session Methods

| Method | Description |
|--------|-------------|
| `session.goto(url)` | Navigate to URL |
| `session.click(selector)` | Click element |
| `session.fill(selector, value)` | Fill input |
| `session.type(selector, text)` | Type text |
| `session.read()` | Smart scroll + hover through content |
| `session.screenshot(options)` | Take screenshot |
| `session.close()` | Close session |
| `session.autoPilot()` | Get AutoPilot instance |
| `session.autonomous()` | Get Autonomous instance |
