## Overview

Connect to a running cykani-browser instance via CDP for remote automation.

## Basic Connection

```javascript
import { connectOverCDP } from 'cykani-stealth';

const session = await connectOverCDP('http://127.0.0.1:9222', {
  humor: true,
  fingerprint: 42,
});

await session.goto('https://example.com');
await session.close();
```

## Docker Connection

```javascript
const session = await connectOverCDP('http://browser:9222');
```

## Remote Server

```javascript
const session = await connectOverCDP('http://your-server:9222', {
  proxy: 'http://user:pass@proxy:port',
});
```

## Session Methods

Once connected, all session methods are available:

```javascript
await session.goto('https://example.com');
await session.autoPilot().signIn({ email: 'user@site.com', password: 'pass' });
await session.screenshot({ fullPage: true });
await session.close();
```
