## Available Presets

| Preset | Hesitation | Precision | Latency | Best For |
|--------|------------|-----------|---------|----------|
| `strike()` | 0.5 | 0.7 | human | General automation |
| `highTrust()` | 0.8 | 0.95 | human | Sensitive sites |
| `aggressive()` | 0.1 | 0.5 | robotic | Speed-critical tasks |
| `natural()` | 0.5 | 0.7 | organic | Relaxed browsing |
| `stealth()` | 0.4 | 0.85 | human | Maximum stealth |

## Usage

```javascript
import { strike, highTrust, aggressive, natural, stealth } from 'cykani-stealth';

// Default
const session = await strike();

// High trust mode
const safe = await highTrust();

// Fast mode
const fast = await aggressive();

// Natural browsing
const relaxed = await natural();

// Maximum stealth
const hidden = await stealth();
```

## Custom Configuration

Override preset defaults with entity configuration:

```javascript
const session = await strike({
  instincts: {
    hesitation: 0.7,  // 0-1, higher = more pauses
    precision: 0.9,   // 0-1, higher = more accurate clicks
    curiosity: 0.3,   // 0-1, higher = more exploration
  },
  operate: {
    latency: 'human', // 'human' | 'organic' | 'robotic'
    headless: true,
  },
});
```
